# Rattrapage Agent Guide

## Project purpose

Rattrapage is a personal tvOS 17+ IPTV player written in Swift and SwiftUI. It is deliberately small and uses only Apple frameworks: SwiftUI, Foundation, AVFoundation, and AVKit.

User-facing agent responses must be in French. Swift identifiers, commits, documentation, and UI strings remain in English. Code comments explaining non-obvious behavior are in French.

## Sources of truth

- `project.yml` defines the Xcode project. Never edit `Rattrapage.xcodeproj` directly.
- `Sources/App/Info.plist` is generated by XcodeGen. Never edit it directly.
- `.mise.toml` defines developer commands. Do not duplicate long `xcodebuild` commands in other documentation.
- `LICENSE` is Apache-2.0. Do not change it unless explicitly requested.

## Required workflow

1. Read `CODEMAP.md` and the files relevant to the requested change.
2. Make the smallest focused change.
3. If `project.yml` or the source/test file list changes, run `mise run generate`.
4. Run `mise run test` when changing parsing, persistence, or other covered behavior.
5. Run `mise run build` before declaring the work complete.
6. Update `README.md`, `CODEMAP.md`, and tests when the public behavior or architecture changes.

Use `mise run doctor` first when a command fails because the local Apple toolchain may be incomplete.

## Architecture rules

- Keep views focused on presentation and UI state.
- Keep parsing, networking, persistence, and AVPlayer lifecycle in `Services/`.
- Keep value types in `Models/` small and immutable when possible.
- Prefer `async`/`await`, native SwiftUI, and Apple frameworks.
- Do not add external dependencies without explicit approval.
- Preserve the deployment target: tvOS 17.0.
- Adding a Swift file requires regeneration through XcodeGen before building.

## Playlist and network constraints

- Accept only sources the user is authorized to access.
- Do not implement bypasses for DRM, authentication, geoblocking, or provider restrictions.
- Handle unavailable or unsupported streams with clear user-facing errors.
- Do not broaden App Transport Security exceptions without an explicit request and a documented reason.

## Validation expectations

- Parser changes: add or update `M3UParserTests`.
- Playlist persistence changes: add or update `PlaylistStoreTests`.
- Project generation changes: run `mise run generate` and `mise run build`.
- Never claim tests or builds passed unless the command completed successfully.
